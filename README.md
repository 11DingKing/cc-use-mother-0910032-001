# 未成年人隐私同意

本项目维护未成年人隐私同意的领域约定、角色边界与样例数据，供后端服务、接口和自动化验证统一使用。当前契约覆盖文博中心运营员、志愿者、监护人、场馆负责人，并明确用途化同意版本、字段级最小权限、历史留档边界、访问决定审计等关键约束。

## 目录

- `domain/contract.json`：领域角色、状态、约束和样例。
- `src/domain_contract/`：契约读取与确定性校验。
- `src/consent_backend/`：隐私同意后端（见下节）。
- `tools/check_contract.py`：命令行摘要检查。
- `tests/`：契约完整性与后端行为回归测试。

## 后端服务（src/consent_backend/）

- `domain.py`：角色、数据用途（紧急联系人 / 健康注意事项 / 服务照片授权）与字段策略——每个用途声明可见角色和每角色最小必要字段。
- `store.py`：线程安全存储。同意链只追加不可变记录，状态机保证已关闭版本（撤回 / 过期 / 被取代 / 监护变更失效）永远不能恢复为生效；`expected_head_seq` 提供比较并交换，过期快照的并发写入被拒绝。
- `services.py`：领域服务。
  - 同意：按用途维护版本、有效期与状态；部分撤回只影响单个用途；有效期届满惰性关闭并留痕。
  - 访问：读取敏感字段时同时校验服务关系（生效岗位分配覆盖该用途）与最小必要范围（角色字段子集），拒绝原因明确。
  - 监护关系：变更即时作废旧监护人签署的全部生效同意，需新监护人重新签署；历史链完整保留。
  - 留档：创建时冻结当时有效同意下的字段；撤回不删除留档，但留档读取限运营员 / 场馆负责人并需书面理由，全程审计。
  - 导出：仅当前监护人可导出；系统侧只保存导出元数据（字段名与状态），不复制原值。
  - 家长授权去向：当前监护人可查看各用途同意现状、谁在何时读了哪些字段、导出与留档记录、监护关系历史。
- `audit.py`：审计条目类型层面只有字段名、决定与理由，不承载敏感原值。
- `api.py` / `server.py`：门面与标准库 HTTP JSON 接口（`python3 -m consent_backend.server` 启动）。

## 验证

测试命令：`python3 -m unittest discover -s tests -v`

编译命令：`python3 -m compileall -q src tools tests`

命令行检查：`python3 tools/check_contract.py domain/contract.json`
